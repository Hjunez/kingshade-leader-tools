This is a test page

It exists to prove two things about the faction's DIBS board, and it needs two people to prove them: that one member cannot release another member's call, and that when two people call the same target at the same moment, exactly one of them gets it.

It cannot touch a real war. The war it writes to is fixed in this page's code and its name begins with sim-, which is the only kind of war the server will let anyone empty or experiment on. The target is a made-up Torn ID that belongs to nobody. Changing the web address does not change either of them.

Nothing you do here is seen by the faction, and nothing here affects any real target, any real war, or your own account.

What this page does, calls and stores

Torn asks every tool that takes a key to say these five things.

Data Storage
Temporary (< 1 day). The test war's board is deleted by the server after twelve hours without a change.
Data Sharing
Faction. Only this faction can read the board.
Purpose of Use
Competitive advantage.
Key Storage & Sharing
Not stored/shared. Your key is never stored on the server, never written to its log, and never shown to another member.
Key Access Level
Public. The lowest level Torn offers is enough.
Torn calls
None from this page. This page never contacts Torn. It sends your key once to the faction's claim server, and that server asks Torn the one question — whose key is this, and is that person in the faction.
Signing in
Your key goes to the claim server in the body of one request. It answers with a signed slip that says your Torn ID and when it runs out. The slip lives in this browser tab only — not in storage — and is replaced from your key when it runs out.
Claim server
Reads and writes one test board at ks-war-room-claims-staging.hans-viklund.workers.dev. Every request is a POST and carries the slip in its body: never in a web address, never in a header. It is sent the test war's name, the made-up target ID, and nothing else about you beyond what the slip already says.
Who a call belongs to
The server takes your Torn ID from the signed slip, not from anything this page puts in the request. That is one of the two things this test exists to show.
Stored in this browser
Your Torn key, in this device's local storage, so you do not have to paste it again between presses. Nothing else — and not the sign-in slip. The Forget key button removes it.
Writes
Nothing in Torn, ever. No attacks, no clicks, no navigation, no page scraping, no background watching, nothing to do with captcha. The only thing this page writes is a line on a test board that no real war can see.
