What "on loan" means here. Torn's own armory data marks an item with the member currently holding it. This page reports exactly that, so a name on the list is Torn's record, not a guess from reading the log.

How long. Loan times come from Torn's armory log, matched by member and item name, because the log never names the exact item. If a member holds more than one of the same item, the newest loans of that name are used, and returns are not taken into account. A loan that is not in the part of the log that was read is shown as longer than the time the log covers — never as a guess.

Manual refresh only. One press, one read. The page never polls in the background and never acts inside Torn.
