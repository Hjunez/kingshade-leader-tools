Kingshade Scripts

Every Kingshade userscript in one place. Pick the one for the device you play on, install it, and you are done.

Userscripts
Before you install

On a computer: you need Tampermonkey in your browser first. Install it from the Chrome Web Store or the Firefox add-ons site, then come back here and press Install.

On Torn PDA: the app has its own script list. Open Torn PDA, go to its userscript settings, add a script, and paste the address of the file you want. Each card below shows the file name.

If pressing Install just opens a page full of text, nothing is broken — select all of it, copy it, and paste it into a new script in Tampermonkey or Torn PDA.

These scripts read Torn's official API and the page you have open yourself. None of them click, attack, travel or act for you — every move in Torn stays yours.

Nothing is stored on any server. Your Torn key, where a script needs one, stays in your own browser and is only ever sent to Torn.
