What this page does with your key
Purpose
Reads the faction member list, the faction's outgoing attack log, five public personal stats for each member and each member's Halloween treat count. It does this only when you press Refresh or Take treat snapshot. Nothing runs in the background.
Access needed
A Custom Key with faction → members and attacks, and user → personalstats and competition. The attack log also needs Faction API Access on your faction position, which the Leader sets in Torn and not on the key. A missing tick box gives error 16 and the page says which call was refused.
Storage
The key lives in this browser's local storage under ks-leader-board-key, shared with the other Leader Tools pages. The numbers this page reads (settings, attack rows, activity values and treat snapshots) are kept under ks-halloween-v1. There is no server and no account.
Retention
Until you press Forget key or clear this site's data in your browser. Forget key removes only the key.
Sharing
Never. The key is sent only to api.torn.com, in a request header, never in a web address. It is not written to the saved data, the exported file or the copied text.
Writes
None. This page only reads. It never attacks, sends, spends or changes anything.
Call pace
At most 50 calls a minute, one queue for everything, so it leaves room for other tools on the same account. Every call is tagged KSHalloween in your own API log.

How to read this table
Hits
Leaves + Mugs + Hosps, the same rule as the War Payout Ledger.
Other wins
Arrested + Looted + Bounty + Special. Counted on their own, not in Hits.
Losses
Lost + Stalemate + Escape + Timeout + Interrupted + None.
Retals
Hits where Torn's retaliation modifier is above 1.
Bonus hits
Hits that landed on a chain bonus (10, 25, 50, 100 and so on) and whose respect equals that bonus.
Avg respect
(Respect from Hits minus the respect from bonus hits) divided by (Hits minus Bonus hits). Respect from assists and other wins is in Total respect but not in this average. Bonus hits are left out because they lift an average by luck, not skill. They are shown openly in their own column.
Energy
25 energy for every attack the member started, win or lose, assists included. It is an estimate: Torn's wiki does not say whether energy is spent on every outcome.
Activity
The difference in Torn's personal stats between the start and the end of the window. Torn returns these by day, so they cover whole days.
Treats
The difference between two snapshots. It is not known whether Torn's count drops when a member spends treats, so a count that went down is marked fell and not hidden.

Manual only, by design. The page reads from Torn when you press a button and never polls in the background. It never acts inside Torn.
