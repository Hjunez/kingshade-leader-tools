Ranked War DIBS guide

How to update the KS scripts before the war, how to check you are on the right version, and how DIBS works once the war is live.

Updated 11 Sep 2026
Before you start
Torn PDAKS Torn War Dibs PDA v1.5.167 + KS FFScouter Call Guard v1.1.4
ComputerKS Torn War Dibs PC v1.0.40 + KS FFScouter Call Guard v1.1.4 (both in Tampermonkey)

You need two scripts on every device you play on. War Dibs puts the DIBS buttons straight into Torn's own war page. Call Guard puts the same DIBS into FFScouter's War Room and is your backup if the Torn-side script ever acts up. You can run on Call Guard alone if you prefer, but it is a thin layer on top of FFScouter's own page, so not everything the War Dibs panel does is available there.

They all install from Kingshade Scripts. Do it today, not when the war starts. Never post or share your API keys anywhere — not in screenshots, not in chat, not in bug reports.

Torn PDA

If you already have KS Torn War Dibs installed

  1. Open Torn PDA. Open Settings, then User Scripts.
  2. Tap the pencil next to KS Torn War Dibs.
  3. Tap Configure, the button next to Remote load/update.
  4. Tap Check for Update. When it offers 1.5.167, tap Update.
  5. Do the same for KS FFScouter Call Guard: pencil → Configure → Check for Update → Update. It must say 1.1.4.
  6. Close Torn PDA completely and open it again.
  7. Open your faction's Ranked War page. The KS panel must show v1.5.167 in the top right corner.

After the update the script is listed as KS Torn War Dibs PDA instead of KS Torn War Dibs. That is the new name — nothing went wrong.

If Check for Update finds nothing, or you never installed it

  1. In Torn PDA → Settings → User Scripts, switch any older KS Torn War Dibs off.
  2. Open Kingshade Scripts and press Install on the Torn PDA card for KS Torn War Dibs.
  3. If a page of text opens instead: select all, copy, then in Torn PDA press + under User Scripts and paste it in. Save.
  4. Close Torn PDA completely and open it again. Check the panel says v1.5.167.

Computer (Tampermonkey)

KS Torn War Dibs PC

  1. Click the Tampermonkey icon in your browser toolbar → Utilities → Check for userscript updates. That updates every installed script at once.
  2. Open the Tampermonkey dashboard and look at the Version column: KS Torn War Dibs PC must say 1.0.40. Only one version may be enabled.
  3. If it still shows an older number: open Kingshade Scripts, press Install on the PC card, and confirm the update in the Tampermonkey window that opens.
  4. Open Torn's Ranked War page. The KS panel must say v1.0.40 TEST. The word TEST is part of this version's label and is expected.

Keep your Torn key and FFScouter key handy in case the panel asks for them again after the update. Do not change anything in FFScouter's Filter & Sort Controls on the war page. Leave Sort: Default and all filters as they are. The only thing you may change is the Show dropdown — FF Score or BS Estimate, nothing else.

KS FFScouter Call Guard

  1. After Check for userscript updates above, KS FFScouter Call Guard in the Tampermonkey dashboard must say 1.1.4. If it still shows an older number, press Install on the Call Guard card on Kingshade Scripts.
  2. Open ffscouter.com/war-room. The KS CALL GUARD panel must show under FFScouter's API key box.
  3. If the panel asks for a key, press Set key and paste your FFScouter key.

FFScouter War Room — the backup for everyone

War Room is FFScouter's own page. Call Guard adds the shared DIBS buttons to it, and it talks to the same server as the Torn-side scripts, so a target claimed on the PDA shows as TAKEN in War Room and the other way round. If the Torn-side script ever acts up during the war, switch to War Room and keep calling from there instead of clicking around.

PDA users: the War Room link inside the KS panel opens it directly.

API keys

Torn key

The Torn-side scripts need a custom Torn key with faction members and wars and user basic. If you created it from the KS panel in August it still works — nothing to redo.

  1. In the KS panel press Create custom API key. Torn opens its key page with the right access pre-filled.
  2. Create the key there and copy it.
  3. Back in the KS panel press Set Torn key and paste it.

FFScouter key

Needed for FF numbers and for the shared DIBS. Press Set FFScouter key in the Torn-side panel, or Set key in Call Guard, and paste the key from your FFScouter account.

Both keys are stored encrypted in your own browser or app and are only ever sent to api.torn.com and ffscouter.com respectively. Nothing is sent to Kingshade. The exact wording is printed inside every panel.

Other scripts

On the computer you also need the FF Scouter V2 userscript from ffscouter.com running on the war page. War Dibs PC reads Fair Fight from FFScouter's own rows and cannot unlock DIBS without it. Torn PDA does not need it — the PDA script fetches Fair Fight itself.

War Stuff Enhanced is not supported. With it installed, War Dibs blocks itself and shows a warning on the war page. Disable War Stuff Enhanced and reload Torn.

TornTools and other war scripts are untested. If the KS panel does not show or looks wrong, turn other war-page scripts off first and reload.

How DIBS works

  • DIBS stays locked until the war is actually LIVE. Before that every button says PREWAR.
  • A target opens for DIBS when it is in Hospital with 2:00 or less left and its FF is between 2.00 and 5.00.
  • First claim wins. You see DIBBED / RELEASE; everyone else sees TAKEN and your name.
  • Click DIBS once. Do not spam it. If several people click at the same moment the server decides the order.
  • Press RELEASE if you no longer want the target. It becomes available again for the others.
  • One active DIBS per player. When your target is down, press RELEASE if the claim is still showing, so you can claim the next one and you are not blocking anyone else.
  • Attacks are still 100% manual. No KS script ever attacks, clicks or navigates for you.

If something looks wrong

Do not keep clicking and do not try to fix it mid-war. Switch to FFScouter War Room and keep calling from there.

These scripts read Torn's official API and the page you have open yourself. None of them click, attack, travel or act for you — every move in Torn stays yours.
