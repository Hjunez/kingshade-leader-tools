Which key selections this needs

faction → members, rankedwars, rankedwarreport and attacks. Missing one gives error 16, which is a tick box, not a broken key. Reading the attack log also needs Faction API access in the faction.

Reads the list of your ranked wars, one war report and that war's attack log, when you press the buttons.
Storage
This browser only. No server, no account. Press Forget key to remove it.
Sharing
Never. Sent only to api.torn.com, in a request header, never in a web address.
Writes
None. Reading only.
