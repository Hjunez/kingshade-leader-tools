What this does with your key
Purpose
Reads your faction's member list, once, each time you press Load members.
Access needed
A Custom Key with the faction members selection enabled. Error 16 means that selection is missing, not that the key is broken.
Storage
Your browser's local storage on this device only. There is no server and no account.
Retention
Until you press Forget key or clear your browser data.
Sharing
Never. The only place it is sent is api.torn.com, in a request header, never in a web address.
Writes
None. This page only reads. It never attacks, sends, spends or changes anything.
Call tag
Every request is tagged KSLeaderBoard, so you can recognise it in your own API key log.

Paste a key and press Load members.

Manual refresh only, by design. The page makes one API call when you press the button and never polls in the background. Background watching of a game you are not looking at is exactly what Torn's scripting rule prohibits, so this page does not do it.

Torn does not publish other players' battle stats. Not for your own members either. This board measures activity and availability, which is what a leader can actually act on.
