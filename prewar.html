What this page does, calls and stores
Data Storage
Only in this browser. Nothing is kept on any server; the figures live in the open tab only. The one thing kept between visits, besides your keys, is the honor number of each player (see Honor bars below).
Data Sharing
Nobody.
Purpose of Use
Competitive advantage.
Key Storage & Sharing
Stored in this browser only. Not shared.
Key Access Level
Public. Honor bars also need the user → profile selection on your Torn key; without it they stay off and the page works as before.

The four Torn reads that load the page are /v2/key/info, /v2/faction/wars, /v2/faction/members?striptags=true and /v2/faction/{opponent}/members?striptags=true. Every Torn request carries . A missing opponent or an error can stop the sequence early.

Honor bars. Each name in Your targets, Full enemy list and Most dangerous can show the player's honor bar behind it, with the name written on it. To know which bar a player wears, this page reads the honor ID from /v2/user/{id}/profile: once per player, one player at a time, at most one read every 6 seconds (so at most ten a minute), starting with Your targets, then the rest of the enemies, then our own members, and only while this page is on screen. A full roster of about 100 players therefore takes about ten minutes; the line above the lists says how far it has come. The picture itself is loaded straight from www.torn.com by your browser, once per honor; this page does not copy it, does not save it and sends no page address along with the request. Torn staff have approved reading the honor ID and loading the picture this way. Only the honor number of each player is kept in this browser (: the number or “no bar”, the time it was read, where it came from and a version, never a key, a picture or a name), for 7 days; after that it is read again. It is removed when you press Forget key and when another key is used. The Honor bars button switches all of it off on this device (): no profile reads for bars, no pictures, plain names. It is on until you turn it off. Where anything is missing — no honor, a key without profile, a picture Torn does not deliver — the name is shown plain.

The colours in Strength comparison show the estimate class and which side leads; they are estimates from FFScouter.

FFScouter receives the IDs from both rosters at https://ffscouter.com/api/v1/get-stats. Its API requires your FFScouter key in the request address. Your Torn key goes only to api.torn.com, in the Authorization header, never in the address. The Torn key never goes to FFScouter and the FFScouter key never goes to Torn. Use keys that belong to you in both fields.

Kept in localStorage: your two keys, and , and the honor numbers and the Honor bars switch described above. The figures are kept in memory in this tab. Nothing is written in Torn. Apart from the honor-bar reads described above, which use your own key one player at a time while this page is on screen, there is no background monitoring, scraping, automatic action, claim server or event server. Saved keys load once when this page opens; subsequent reads of the war and the figures require Refresh.
